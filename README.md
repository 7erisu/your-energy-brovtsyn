#  Your Energy

**Your Energy** — це мій навчальний проєкт, створений під час проходження курсу з Frontend-розробки.

Додаток дозволяє переглядати вправи, додавати їх в обране, ставити рейтинг та підписуватись на розсилку.

Проєкт створений з використанням **HTML, CSS та Vanilla JavaScript**, а також працює з **REST API**.

---

##  Використані технології

У проєкті використано:

- HTML5
- CSS3 (Flexbox, Grid, адаптивна верстка)
- JavaScript (ES6, модульна структура)
- Vite
- Node.js
- npm
- LocalStorage
- REST API

---

##  Реалізований функціонал

У додатку можна:

- переглядати категорії вправ
- відкривати список вправ
- користуватися пошуком
- відкривати модальне вікно з деталями вправи
- додавати вправу в обране
- видаляти вправу з обраного
- ставити рейтинг вправі
- підписуватись на email
- переглядати Quote of the Day
- користуватись окремою сторінкою Favorites

Обрані вправи зберігаються в **LocalStorage**.
